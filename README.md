# Iran-Housing-Market-Intelligence-Ongoing
Performed extensive data cleaning and validation on real-estate listing data.
Analyzed missing values and developed rule-based methods for recovering information from listing text.
Implemented domain-based validation rules and suspicious-value detection for real-estate prices.
Applied hierarchical outlier detection using property-type and geographic groups.
Developed approaches for detecting duplicate and highly similar real-estate listings.
Extracted structured features from Persian-language listing descriptions.
Performed geographic data processing and prepared the dataset for further market analysis and visualization.
Status: Ongoing; further market analysis and dashboard development in progress.
